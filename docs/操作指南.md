# 七阶段工程交付操作指南

## 更新与启动

从 GitHub 下载 main 分支 ZIP。先备份原来的整个 `data` 文件夹，关闭旧程序，
再更新代码；保留自己的项目数据，不要用测试数据覆盖。新代码仍能读取旧项目，
进入“工程交付 · 7 阶段”后可启用新的工作区。

Windows 在项目文件夹运行 `start.bat`，出现启动完成提示后打开
`http://localhost:8000`。脚本已加入 PyYAML 纯 Python 构建开关，默认采用
Uvicorn/h11，减少新 Python 版本的编译依赖。本环境验证的是 Python 3.12；
不把它描述成已经在用户的 Windows / Python 3.15 上完成验证。

OpenDSS 是可选原生依赖。需要实际工况计算时，在对应虚拟环境安装：

```cmd
.venv\Scripts\python.exe -m pip install -e ".[engineering]"
```

可选原生依赖是否支持当地 Python 版本，需要单独验证；不安装也能录入工程、
生成材料、审核证据与打包。软件不会因为缺少仿真引擎而伪造计算结果。

## 项目准备

1. 创建项目，在 Design inputs 填写客户、地址、NMI、DNSP、电压、容量和导出限额。
2. 打开 **工程交付 · 7 阶段**，填写操作员工姓名。姓名用于操作记录，尚不是登录认证。
3. 可使用“建立空白 PV 拓扑骨架”。骨架只有编号及连接关系，没有已核实的额定值或定值。
4. 逐组填写断路器、变压器、电缆、逆变器/PCS、CT/VT、逐相二次端子、保护功能及控制逻辑。
   每个编号唯一；电缆起终点必须引用实际声明的设备或母线编号。
5. 一旦使用工程设备表，容量计算与图纸共用它，不能再用旧参数编辑器覆盖设备。
6. 上传测绘来源，录入现场实际坐标、设备对应编号与电缆路径。软件不会猜测现场位置。
7. 保存工程设计后，图纸、矩阵和技术文件会自动更新。

## 规范与材料审核

上传 NS194 / NS238 原文件为 `standard` 附件，填写签发方和文件编号。系统识别已提供
副本的 SHA-256 指纹。选择规范版本，记录适用条款、工程师审核人和日期。
**识别到文件不等于所有项目条件已经合规，也不代表已经在线核实它是最新版本。**

已确认提供的版本：NS194 Revision 5（2026-09-10）；NS238 Amendment 0（2015-05-04）。
注意 NS194 的适用防孤岛方案不能把普通 Shunt trip 当作默认合规方案；NS238 的网络
兼容水平不能直接充当每个客户的电能质量排放分配。

每个型号分别关联真实 CEC 证据；按要求上传制造商声明、温升、配合、PQ 和故障研究。
附件先是 uploaded 状态，审核人查阅原始文件后填写审核依据，才能记录接受。
技术设计改变后，绑定旧设计的证据需要更新；仅补录后续 Offer 编号不会改变工程设计。

## 图纸与递交

在项目文件区预览 SLD、三相保护图、跳闸矩阵、现场布置、控制说明、MSB 准备稿等。
HTML 和 SVG 可使用 **打印 / 保存 PDF**。解决待处理项，再到 Documents 记录工程师签核。

完成前 3 个阶段后，可冻结正式的“递交前设计包”。此包不要求先完成施工调试。
员工自行进入 Ausgrid 等官方门户，核对现行申请路径、官方表单及文件格式并递交。
本软件不会替代用户点击提交、付款或接受 Offer。

保存真实的递交回执、RFI、Offer、批准图纸及定值、缴费凭证、Job Number 和 DER 编号。
它们必须来自实际签发方，软件不生成这些官方识别码。

## 调试、验收及移交

根据已获批定值录入二次注入结果、仪器校准、操作人员资质、实测动作值和时间。
上传测试人员签署的原始报告。适用的复杂保护方案还需获批测试计划、见证报告等。
完成通信能力和失效场景测试，记录通信丢失、控制器失电、Watchdog 与恢复闭锁结果。

最后上传 CCEW、验收记录和实际允许并网/送电文件。软件检查记录和材料是否齐备，
不会替代现场测试、签发证书或授予送电权限。

设计包、调试包、最终移交包分别检查。冻结后的历史 ZIP 不会被后续修改覆盖，
可按其 SHA-256 和清单追溯。具体哪些条件尚缺，可展开每个阶段的待处理列表。

## 数据与访问

默认数据在 `data/projects`，原附件在 `data/attachments`，冻结包在 `data/releases`。
备份时关闭服务并复制整个 data 目录。删除项目会同时删除该项目附件和冻结包。

目前没有员工账户、角色权限或托管备份服务。默认只监听本机；如部署公司共享服务器，
应先接入公司已认证的访问入口和备份体系。员工姓名记录不等于经过身份认证的数字签名。
